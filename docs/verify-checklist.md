# 原版实机核对清单（verify-checklist）

> 来源：`docs/VERIFY.md` 里方式含 **P**（需要在原版里实机操作）、状态还不是 ✅ 的项，截至 2026-09-28（M9 台湾图终验之后）；§5 是 2026-09-30 接入原版另外 3 张图（大陆、日本、美国）后新增的核对项与逐图目视巡检。
> 本文件是给「拿着原版 v2.06 实际去玩」的人用的操作手册：每项写清**在原版里怎么操作、观察什么**，以及**我们现在的默认行为**。
> 结论请回填到 `docs/VERIFY.md` 对应行（状态、结论、证据），再按该文件开头的「回写路径」改代码：先改数据表或 `RuleConfig` 默认值 → 刷新 golden → 升 `ENGINE_VERSION` 次版本号 → 同步 `docs/DEVIATIONS.md`。

## 0. 准备

- **版本**：Steam 版 `Game/rich4.exe`（v2.06，sha256 `110b29f9…`）。v3.11（`MultiverseJourney/`）的规则代码与 v2.06 逐项一致（VERIFY V-E1…V-E9），两个都可以，但请在结论里写明用的是哪个。
- **开局设置**（除非某项另有要求）：關卡一「台灣」；4 人：自己 1 个真人 + 3 个电脑；總資金選最高（300000，方便买卡买道具）；期限「無限」；勝利條件「無」。
- **存档复现**：原版工具列有「存檔 / 讀檔」。每次在触发之前先存档，观察完读档重来，同一件事至少看 2 次（随机事件看 3–5 次）。
- **弄到需要的卡和道具**：走到「卡片格」随机得卡；停在「商店」用點券买卡和道具（商店两页：卡片、道具）；點券不够时多踩「點券格」、玩小游戏。命运、新闻格是随机的，只能多走几圈碰运气。电脑也会主动对你用卡——要观察「被陷害」一类的效果时，身上别带免罪卡、嫁禍卡。
- **计数方法**：以右下角日历的日期和「谁在行动」为准。一个「回合」= 轮到该角色一次（被跳过也算一次）。建议边玩边记：日期 → 该角色这次轮到时发生了什么（被跳过 / 走回棋盘 / 掷骰前进 / 停在原地）。
- **截图**：只用于核对，截图与录像留在本机（`.cache/` 或仓库外），**不要提交进仓库**。
- **回报格式**（一项一段即可）：`V-Rxx｜版本｜操作了几次｜看到了什么（尽量带日期与回合数）｜结论`。

## 1. 优先级

先做影响每局都会遇到的：**V-R1、V-R2、V-R15、V-R17、V-R20、V-R5、V-R6**；其余按遇到的机会顺手核对。**V-R18** 需要截图（只做本机对照）。

## 2. 实机规则（V-R）

### V-R1 坐牢实际经过几个回合；停留卡、乌龟卡的次数；被嫁祸回来的天数
- **操作**：
  1. 身上带陷害卡，轮到自己时对视野内的一个电脑用陷害卡（入狱 5 天），记下当天日期。
  2. 之后每次轮到那个电脑都记一笔，直到它掷骰前进为止。
  3. 乌龟卡：对一个电脑用，数它之后有几个回合每回合只走 1 步；再对自己用一次，数自己几回合只走 1 步。
  4. 停留卡：对电脑用一次、对自己用一次，分别看是「下一次」还是「这一次」停在原地、停几次。
  5. 嫁祸 4 天：自己带嫁禍卡、不带免罪卡，等电脑对你出陷害卡；弹出嫁祸选择时选回**出卡的那个电脑**，看它入狱几天。
- **观察**：入狱 5 天时有几个回合是「在监狱里被跳过」；出狱那个回合是「走回棋盘就结束、不掷骰」，还是「出狱后照常掷骰前进」。
- **我们当前**：坐牢 N 天 = N 个受阻回合 + 1 个「走回棋盘、不掷骰」的回合（事件 RETURNED）；乌龟卡对别人 3 次、对自己 2 次；停留卡对别人是下一次前进停住 1 次，对自己是本回合停住；陷害被嫁祸回出卡者写 4 天。
- **若不同**：出狱当回合照常行动 → 改 `flow/turn.ts` 的 RETURNED 分支（g_arbitration §3.3 的 MY/NU 写法）；天数不同改 `data/tables/combat.ts`。

### V-R2 首回合跳伞后是否立即掷骰、是否结算落点
- **操作**：开新局，看每个角色第一次轮到时跳伞落地之后的流程。重复开局 3 次，留意落在空地 / 别人地上 / 特殊格（银行、商店、命运）的情况。
- **观察**：落地后是否马上让你掷骰前进；落在空地上会不会先问「要不要买」；落在银行 / 命运格会不会先结算那一格。
- **我们当前**：落地后**不结算**落点，随即照常进入回合菜单、可以掷骰（⚑，architecture §17）。
- **若不同**：落地先结算 → 在 PARACHUTE 之后插入落点结算；落地后本回合结束 → 首回合跳过掷骰。

### V-R3 梦游者停下时：付不付过路费、会不会触发地雷和神明
- **操作**：对电脑用梦遊卡（5 天），在它的梦游路线上放地雷、路障，并留意它停在别人（包括你）的地上、停在有神明的格子上时发生什么。
- **观察**：它停在你的地上你有没有收到过路费；踩到地雷是否住院；停在神明格是否附身；是否能投资（买地、加盖）。
- **我们当前**：梦游者停下时照样触发路面物件、神明与显灵 ⚑；梦游期间不能收租、不能投资（卡片说明）；过路费照付（architecture §20.2）。

### V-R4 定时炸弹爆炸是否伤及周围 3×3 的其他人
- **操作**：把定时炸弹放在路上让别人（或自己）捡到，引信归零时让携带者身边（前后两三格内）也站着别的角色；也试一次放在路上不被人捡、原地爆炸。
- **观察**：爆炸时除了携带者（或所在格的人），附近的角色有没有一起住院、附近的房子有没有降级。
- **我们当前**：PROGRAM 只影响携带者和所在格（`bombBlast: 'program'`）；MANUAL 为半宽 100 的方窗（`manual3x3`）。
- **若不同**：改 `PROGRAM_RULES.bombBlast`。

### V-R5 满手（15 张）时再得一张卡：自动丢还是让你选
- **操作**：把手牌攒到 15 张（卡片格、商店、命运都能得卡），再踩一次卡片格或在商店再买一张。
- **观察**：有没有弹窗让你从 16 张里选一张丢掉；如果没有，少了的是哪一张（最便宜的？新拿到的？最早的？）。
- **我们当前**：PROGRAM 自动丢最便宜的一张（`handFull: 'autoCheapest'`）；MANUAL 先入手再弹 DISCARD_CARD 让你选。

### V-R6 星期日银行能否使用
- **操作**：把角色停在银行 / 路过银行的那天正好是星期日（看日历的星期），分别试 ATM（路过）和柜台（停下）。
- **观察**：ATM、柜台是否可用，有没有「今天休息」之类的提示。
- **我们当前**：PROGRAM 星期日照常营业（`sundayBankClosed: false`）；MANUAL 星期日 ATM 与柜台都拒绝（BANK_REJECTED{sunday}）。

### V-R7 魔法屋：名单有自己时能否选全部效果；坐牢住院能否被免罪 / 嫁祸挡掉；「拍卖当格」的钱归谁
- **操作**：
  1. 停进魔法屋，等到条件名单里**包括你自己**的那种情况，看 12 个效果（星区）是否都能点。
  2. 身上带免罪卡（另一次带嫁禍卡），让魔法屋的「坐牢」「住院」落到自己身上（名单只有自己时最容易）。
  3. 选「拍卖脚下地产」（让名单里某人脚下的地被拍卖），看成交价付给了谁。
- **观察**：是否有效果点不了；免罪卡 / 嫁禍卡有没有自动触发或询问；拍卖的钱进了谁的现金 / 存款，流拍后地变成谁的。
- **我们当前**：名单含自己时真人仍可选全部 12 种效果；坐牢 / 住院走免罪 → 嫁祸（可以挡掉）；「拍卖脚下地产」以目标本人为卖方、成交款进目标存款，流拍变无主 ⚑。

### V-R8 命运坐牢能否用免罪卡；命运 / 新闻罚款能否用免费卡
- **操作**：身上带免罪卡、免費卡、嫁禍卡，多踩命运格，等到「坐牢 / 出国 / 住院」和「罚款」类命运。新闻同理（新闻格或每月初的新闻）。
- **观察**：坐牢类命运是否被免罪卡抵掉（或问嫁祸）；罚款类命运是否问你用免費卡 / 嫁禍卡。
- **我们当前**：PROGRAM 命运坐牢 / 出国 / 住院（命运 6、7、12、13、33–36）走免罪 → 嫁祸；罚款直接付（`freeCardOnFines: false`）；神明加持不作用于新闻（`blessingOnNews: false`）。MANUAL 两者都为 true。

### V-R9 投降流程
- **操作**：在自己的回合用工具列 / 菜单里的投降。之前先有几处（> 3 处）地产。
- **观察**：投降后你的地产去哪了（全部拍卖、随机拍卖几处、变无主）；拍卖成交款进了哪里；你的角色是否变成乞丐留在棋盘上；有没有让你指定死神附身谁。
- **我们当前**：与破产共用清算（释放的地产 > 3 处时随机拍卖 3 处，成交款进公库）；投降者先指定死神附身对象，随后按破产出局并成为乞丐 ⚑。

### V-R10 四大恶人：雇用后何时开始走；间谍偷租金；被关回去的时机
- **操作**：去监狱 / 医院花 300 點券雇一个恶人（小偷、强盗、流氓、间谍各试一次），记下雇用当天。
- **观察**：恶人从哪一轮开始走、每次走几步；间谍停在别人的住宅 / 设施 / 企业上时，钱从谁那里到了谁那里、多少；恶人什么时候被送回监狱 / 医院；雇主破产时恶人去哪。
- **我们当前**：雇用后在放出来的同一轮、所有玩家行动完之后开始行动（rand % 9 + 2 步，乌龟 1 步）；间谍取走住宅的上次过路费 / 设施的上次收费 / 企业的本月盈余（为负时雇主反付）⚑；回到自己的保释格且离开过门口即送回；雇主出局时送回。

### V-R11 红卡、黑卡的有效天数；个股停牌天数
- **操作**：对一支股票用红卡（另一次用黑卡），看之后几个开市日涨停 / 跌停；对同一支股票先红卡再黑卡看是否抵消。停牌：等新闻「个股停牌」，数停几天。
- **观察**：涨停 / 跌停持续的开市日数；红黑是否抵消；停牌实际天数（文案写 10 天）。
- **我们当前**：PROGRAM 红黑卡写当天 + 次日各一次、后写覆盖前写（`redBlack: 'program'`）；MANUAL 3 个开市日、异色互相抵消。个股停牌 15 天（exe 写 15，`stockSuspendDays: 15`），前端文案按实际天数显示。

### V-R12 大财神附身时住旅馆；死神与送神符
- **操作**：让大财神附身（踩到大财神），期间停在别人的旅馆上；另找机会让死神附身，用送神符试着送走，并留意别的神明能否把死神挤掉。
- **观察**：大财神附身时住旅馆是否免费、是否还要住几天；送神符能否送走死神；死神附身期间踩到别的神会发生什么。
- **我们当前**：大财神使费用为 0 时不住宿；PROGRAM 送神符能送走死神（`deathGodDispellable: true`，MANUAL 为 false）。

### V-R13 保险重复投保；航空出国天数
- **操作**：停在保险公司投保，投保期内再投一次，看保险天数；停在航空公司被转盘转到出国 n 天（n = 0、1、2、3），数实际离开几个回合、何时回来。
- **观察**：第二次投保后的保险天数是「重新计」还是「累加」；出国 n 天的受阻回合数与回来那回合能否掷骰；n = 0「不用出國」是否收费。
- **我们当前**：重复投保累加（(旧值 + 新天数) & 0x7f）；出国 n 天 = n 个受阻回合 + 1 个走回棋盘的回合，n = 0 不收费 ⚑。

### V-R14 月结冠军 / 悲情人物有无奖金；点券超过 65535
- **操作**：看每月 1 日的月结颁奖画面前后，冠军与悲情人物的现金 / 存款 / 點券有没有变化。
  点券溢出（可选）：正常游玩几乎攒不到 65535。可行的办法是改存档——在原版里存档，用十六进制编辑器把自己的點券改成 65500 左右（先记下当前點券数，在 `SAVE*.DAT` 里搜这个 16 位小端数值定位），读档后再得一次点券；或者把这份 `SAVE*.DAT` 提供给我们（VERIFY 开头的 P 方式允许），由导入工具读出点券字段比对。做不到就跳过这半项，结论里写「点券溢出未核实」。
- **观察**：颁奖是否附带奖金或点券；点券超过 65535 后是停在 65535 还是回绕成小数目。
- **我们当前**：月结只评出冠军与悲情人物（MONTHLY_REPORT），不发奖金 ⚑；点券默认饱和到 65535（DEV-01，原版为 uint16 回绕）。

### V-R15 首次新局的默认总资金；受困者能否参加拍卖、能否被选为嫁祸目标
- **操作**：
  1. 在一台**从没玩过**的环境（或删掉原版的设置 / 存档后）开新局，看設定画面里总资金默认选的是哪一档。
  2. 有人被拍卖（拍卖卡、法院拍卖新闻）时，让某个电脑正在坐牢 / 住院 / 出国，看它有没有出现在竞拍名单里。
  3. 自己带嫁禍卡被陷害时，看嫁祸候选里有没有正在坐牢 / 住院的人。
- **我们当前**：默认 200000（exe 默认档位下标 1）；受困者（坐牢、住院、住宿、出国、冬眠、梦游）与现金 ≤ 起拍价者不能参加拍卖，卖方不能出价；嫁祸目标的受困限制未设（候选为在场的其他玩家）。

### V-R16 工程车拆房；换地卡是否交换地契期限
- **操作**：开工程车，分别让它**经过**和**停在**别人有建筑的地上；用换地卡把自己的一块地与别人的地交换，交换前后看两块地的地契（到期日）。
- **观察**：工程车是经过就拆、还是停下才拆，拆 1 级还是拆平；换地后地契到期日跟着地走还是跟着人走。
- **我们当前**：PROGRAM 工程车停在别人有建筑的地上就清到 0 级（`engineeringVehicle: 'program'`；MANUAL 经过和停留都拆 1 级）；换地卡连同地契期限一起交换 ⚑。

### V-R17 真人每回合能用几张卡、几个道具
- **操作**：轮到自己时连续用两张卡（比如先用停留卡再用乌龟卡），再在同一回合用两个道具（路障、地雷）。
- **观察**：用过一张卡 / 一个道具之后，卡片栏 / 道具栏是否还能再用；有没有提示。
- **我们当前**：引擎对任何座位都不设上限（一回合内非终结操作最多 40 次，防刷）；电脑 AI 按硬币在用卡和用道具之间二选一（architecture conflicts_resolved）。

### V-R18 企鹅挖宝与喜从天降的宝物图标 ↔ 名称 / 分数对照（截图）
- **操作**：玩几局企鹅挖宝、喜从天降（设置里打开「動畫過程」，在小游戏格停下时选择亲自玩）。每种宝物各截一张挖出 / 接住时的画面，连同得分变化。
- **观察**：每种图标对应的名称和加减分；企鹅记忆阶段（开局前 1 秒）地上露出的是不是宝物的**种类**（我们按 exe 0x413f39 画出种类图标）。
- **我们当前**：原版皮肤按 Panel#80 / #95–99 的帧号画宝物（帧语义由 exe 载入点推断）；程序化皮肤的企鹅记忆阶段只画不分种类的土堆（与原版不同，见 DEVIATIONS DEV-20）。截图只留在本机。

### V-R19 CONSTRUCTION_PICK 能否跳过（加盖级数已核实）
- **操作**：做建设公司的董事长，停在建设公司上，看选择免费加盖地产的画面有没有「不选 / 取消」。
- **我们当前**：董事长加盖 2 级（exe 调用两次，已核实）；选择画面不能跳过（`canSkip=false` ⚑）。

### V-R20 住旅馆 n 天实际受阻几个回合（尤其 n = 1）
- **操作**：多次停在别人的旅馆上（转盘转出 1–4 天），记录每次转出的天数与之后被跳过的回合数、回到棋盘那回合能否掷骰。
- **观察**：住 1 天是否完全不受阻；住 n 天是否受阻 n − 1 个回合。
- **我们当前**：DEV-13：住 n 天统一失去 n 个回合（n = 1 也失去 1 个回合）⚑。原版代码写的是 n − 1（n = 1 时不受阻）。实机若确认 n = 1 不受阻，可以撤销 DEV-13。

### V-R21 挤兑期间 ATM 能否取款；特別融資额度与董事长易主
- **操作**：等新闻「银行挤兑」，挤兑期间路过银行（ATM）试取款、存款，停在银行柜台试贷款；做银行董事长时去柜台看「特別融資」的额度，融资后让别人抢走董事长，看要不要马上还。
- **观察**：挤兑期间 ATM 能存 / 能取吗，柜台能贷款吗；融资额度是多少（与其他玩家的存款合计有什么关系）；董事长易主时融资是否被强制归还。
- **我们当前**：挤兑期间 ATM 只能存、柜台不放款；融资额度 = 其他在场玩家存款合计 − 已融资额；董事长易主不强制归还 ⚑（DEV-18：挤兑用全场一个按日倒数的计数）。

### V-R22 研究所换项目时进行中的研发
- **操作**：拥有研究所，选一个研发项目，没到 5 天时再停在自己的研究所上，改选另一个项目；另一次改选同一个项目。
- **观察**：旧项目的进度是保留还是作废；新项目从几天开始计。
- **我们当前**：选同一项目保留进度；选不同项目作废旧项目（RESEARCH_CANCELLED），新项目重新计 5 天 ⚑。

### V-R23 嫁祸卡转移的范围；免费卡抵掉设施费时住宿 / 出国 / 投保
- **操作**：带嫁禍卡停在别人的旅馆 / 航空公司 / 保险公司上，出现嫁祸询问时转给别人，看住宿 / 出国 / 投保落在谁身上；另一次用免費卡抵掉设施费，看还要不要住宿 / 出国、保险有没有生效。
- **我们当前**：嫁祸只改变谁付钱，住宿 / 出国 / 投保仍落在落点者身上；用免费卡抵掉设施费、企业费时住宿 / 出国 / 投保一并取消 ⚑。

### V-R24 复仇卡生效后，原出卡者能否用自己的免罪 / 嫁祸卡挡掉
- **操作**：自己带复仇卡，等电脑对你用陷害卡或梦游卡；最好那个电脑身上有免罪卡（看不到手牌时多试几次，或自己出陷害卡、让电脑带复仇卡）。
- **观察**：复仇反弹到出卡者身上时，出卡者的免罪 / 嫁祸卡有没有触发。
- **我们当前**：复仇卡触发后出卡者直接受罚 5 天，不再检查出卡者的被动卡 ⚑。

### V-R25 同盟期间的敌意衰减；一方到期时另一方
- **操作**：对一个电脑用同盟卡，之后观察它是否还会对你用坏卡；同盟到期时看双方是否同时解除（原版画面上的同盟标记）。
- **观察**：结盟前对你敌意很高的电脑，结盟期间 / 到期后是否立刻对你出坏卡；两边的同盟标记是否同时消失。
- **我们当前**：每个自己的回合双方敌意各 −20 × 物价指数、不低于 0 ⚑；任一方到期即双方同时解除（ALLIANCE_EXPIRED）。

### V-R26 破产时身上的定时炸弹去向
- **操作**：让一个现金很少、身上带着定时炸弹的角色破产（可以让它连付几次大额过路费）。
- **观察**：它破产后炸弹是留在它所在的格子上、消失、还是回到商店库存。
- **我们当前**：先放回所在格，格上已有物件或不能放时回库存（ITEM_LOST{bankrupt}）；然后附身神明离开、搭档刷出，再解除同盟 ⚑。

### V-R27 传送机的被传送物与目的地是否受视窗限制
- **操作**：用传送机，看可选的「被传送物」（人、神明、路面物件、房屋）与「目的地」是否只能在画面视窗（440 × 440）内选；试着把房屋搬到别处，看地主、等级、地契是否一起搬。
- **我们当前**：两者都限定在视窗（世界坐标方窗近似，DEV-04）内；搬房屋时地主、等级、类型、地契、研发一起搬 ⚑。

### V-R28 新闻「延长刑期 / 延长住院」时投保者是否理赔
- **操作**：投保期间让自己坐牢或住院，等到新闻「延长刑期」「延长住院」，看现金有没有增加（理赔）。
- **我们当前**：PROGRAM 不理赔（exe 新闻 1 / 3 只改关押天数）；MANUAL（`blessingOnNews`）照赔 ⚑。

### V-R31 梦游卡停放座驾、梦游结束装回；开着工程车时用机车 / 汽车
- **操作**：① 让一个骑汽车（或机车）的电脑中你的梦遊卡，数它梦游了几个回合，看它醒来那一回合是不是又坐回汽车；另一次在它梦游期间用抢奪卡抢走它背包里的那台车，看醒来时是不是步行。② 自己开工程车（记下剩余天数），让电脑对你用梦遊卡，醒来后看工程车还剩几天。③ 开着工程车时打开道具欄，点机车 / 汽车道具；另一次开着工程车（骑机车时只选 1 颗骰子再开）等它到期，看换回机车后骰子数是几颗；再一次开着工程车走进魔法屋被「卖光道具」，看得到多少点券。④ 整个过程留意换车时有没有对话框、台词或特别的音效。
- **观察**：① 醒来那一回合装回、背包里的车少一台；被抢走则仍步行。② 工程车天数在梦游期间不减，醒来那一回合照常算一天。③ 能用、工程车直接没了（不退还），开工程车时收进背包的车还在；到期换回机车后是 1 颗；卖光时工程车按 150 点券算进去。④ 只有用道具换车时角色说一句台词，其他时候只换外观。
- **我们当前**：exe 静态分析的结论即如上（architecture §34，ENGINE_VERSION 0.6.0）；用道具换车只换外观、说道具台词（DEV-36 已修），另有一句所有道具通用的「XX 使用了XX」提示。
